# PACk IA PME, landing « patron de PME »

Page statique (HTML et CSS, aucun script, aucun cookie, aucun service tiers), publiable par GitHub Pages.

## Avant de passer en ligne publique
1. Retirer `<meta name="robots" content="noindex, nofollow">` de `index.html`, `mentions-legales/index.html` et `confidentialite/index.html`.
2. Remplacer `Disallow: /` par `Allow: /` dans `robots.txt` (ou supprimer le fichier).
3. Vérifier l'adresse du siège sur l'extrait Kbis (le certificat Qualiopi mentionne une autre commune).
4. Relire les prix, la garantie et les chiffres d'études.
